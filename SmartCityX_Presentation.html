PROBLEM STATEMENT

Why SmartCityX?

Cities generate thousands of reports, sensor readings, and emergency alerts every minute. Manual processing is impossible — DSA algorithms handle this at scale.

🏙️ What the City Needs
• Fast search across 30+ citizen reports and documents
• Auto-correct misspelled service queries
• Detect emergency keywords instantly in alert streams
• Optimally allocate resources within budget
• Find critical infrastructure bottlenecks
• Process IoT sensor data in real time
⚡ How DSA Solves It
• KMP / Aho-Corasick → Search 45 records in O(N+M)
• Damerau-Levenshtein → Correct typos in O(N×M)
• Bitmask DP → Optimal allocation in O(2^N)
• Suffix Array + LCP → Document similarity O(N log N)
• Ford-Fulkerson → Max flow + bottlenecks O(V·E²)
• SAT / Vertex Cover → NP-hard planning problems

② Suffix Array: Sort all suffixes — "road m..." appears near top in both
③ Kasai LCP: LCP[i] = common prefix length between adjacent suffixes
④ Cross-doc scan: Find pair where one suffix from DocA, other from DocB
⑤ Score: 2 × 24 / (52 + 49) × 100 = 47%
